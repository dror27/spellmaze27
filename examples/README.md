# SpellMaze content examples

Hand-made examples for [the content guide](../docs/CONTENT_GUIDE.md):

| Folder | Kind | Zip |
|---|---|---|
| `fruits/` | word list (12 fruits, pictures, a word text, and it names its game) | `zips/Fruits.zip` |
| `my-first-game/` | game with three levels, including a plus-shaped board | `zips/MyFirstGame.zip` |
| `ocean-skin/` | skin | `zips/OceanSkin.zip` |

To try them, download the three zips, then in the game open CONF › **Import Zip Files …** and choose them.
Select **Fruits** under CONF › Game and **Ocean** under CONF › Skin.

Each folder holds one UUID folder, which is what gets zipped. To make your own item, copy a folder and
**generate new UUIDs** (`uuidgen` on a Mac) rather than reusing these.

The fruit pictures are simple generated placeholder cards.
