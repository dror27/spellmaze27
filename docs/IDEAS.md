# Ideas for new SpellMaze content and features

A list of ideas for new word lists, games, levels and skins, plus some features. Each idea is marked:

* 📦 **content**: can be made today as a zip, with no code (see [CONTENT_GUIDE.md](CONTENT_GUIDE.md))
* 🛠 **code**: needs a change to the game

The keys mentioned are the ones documented in the content guide.

---

## Word lists (ontologies)

| Idea | Kind | How |
|---|---|---|
| **Spelling bee lists by grade** (K–8). Each word gets a short definition, shown when it is spelled. | 📦 | `words.txt` with `text-delimiter` `|`: `NECESSARY|necessary|needed; essential`. Pair it with the *Spelling Bee* game below. |
| **Vocabulary for language learners**: Spanish, French, Hebrew… words, with the English meaning as the text. | 📦 | The word list in the target language, `voice-language` set to it (`es`, `fr`, `he`…), the translation as the word's text. The computer voice pronounces each word. |
| **Equations**: true sums and products such as `2+3=5` and `4*6=24`. Players build equations from tiles. | 📦 | Any characters are allowed in words, so the tiles become digits and `+ - * =`. Generate all true equations of up to 2 digits with a small script. The original game's todo list had math levels. |
| **Elements of the periodic table**, with the symbol, number and a fact as the text. | 📦 | `HYDROGEN|Hydrogen (H, 1)|The lightest element.` Add picture cards for the common ones. |
| **Capital cities**, with the country as the text (`PARIS|France`). Goes well with the existing Flags lists. | 📦 | A text list; images optional. |
| **Picture domains for young children**: animals, fruit, vehicles, body parts, colors, shapes, birds, dinosaurs, planets. | 📦 | Like *Mammals*: an `images/` folder gives it the *Learning* game automatically. Use freely licensed pictures, e.g. Wikimedia Commons or your own photos, and keep their licenses in the zip. |
| **Early readers (phonics)**: three-letter CVC words (CAT, DOG, SUN) with pictures. | 📦 | A small list plus a *Kids* game with a 3 × 3 board (see games). |
| **Names**: a class, a family, a football team, as in the original's "My Friends" list. | 📦 | Already possible for players through CONF › Game › Your Own Words. For a shared list, use `split-words` with full names. |
| **Other sign-language alphabets**, BSL or a sign alphabet of another language, in the style of *Finger Spelling*. | 📦 | Letter pictures with `skin` › `images` › `symbols_A` …, and a "Show Letters" setting (`prefs`) like Finger Spelling's. |
| **Braille**: letters shown as Braille cells. | 📦 | Letter pictures (`symbols_A` …) of Braille cells, generated by a script. |
| **Japanese kana** (hiragana or katakana words) or Greek. | 📦 | Words in that script, `voice-language` `ja` or `el`. Kana and Greek letters work as tiles. |
| **Emoji puzzles**, words written in emoji. | 🛠 | Emoji are two-part characters internally, and the board splits them. The language and piece code would need to treat them as one character. |

## Games (sets of levels)

| Idea | Kind | How |
|---|---|---|
| **Spelling Bee**: hear a word, then spell it from its scrambled letters. | 📦 | `dispenser_word_by_word`, `dispenser_scramble`, `logic_line`, `speak_word_on_dispensed` (web version), `show_hint_word` off so the word is heard, not seen. Use with a word list that has texts. |
| **Kids**: big tiles, slow letters, nothing to lose. | 📦 | A 3 × 3 or 4 × 4 board, `dispenser_tick_period` 3, `game_over_grace` 0 (never lost), `show_hint_pieces`, `valid_min_word_size` 2, no decorations. |
| **Shapes**: every level a different board shape (plus, ring, L, staircase, islands, a diamond made of stacked rows). | 📦 | Multi-line `board_formula` (see "Board formulas"). A ring is 4 rectangles: top, bottom, left and right. |
| **Spin Cycle**: the board turns a quarter with every new letter, not with every word. | 📦 | `logic_viewtrans` with `logic_viewtrans_event` `pieceDispensed:` and `logic_viewtrans_slices` 4. Other events also work: `pieceSelected:`, `invalidWordSelected:`. |
| **Fog**: letters fade while they move around. | 📦 | `logic_fader` with a short `logic_fader_pace` together with `logic_nudge` + `Chaos`. |
| **Bomb Squad**: lots of bombs, letters only on a cross. | 📦 | `logic_decorator_bomb_prob` 0.3 with `logic_disabler` pattern 0. Bombs clear the cross for you. |
| **Long Words**: 7 letters or more on a 6 × 6 board, slow, with more jokers. | 📦 | `valid_min_word_size` 7, `dispenser_joker_prob` 0.06, `hint_max_word_size` 0. |
| **Zen**: an endless, calm mode. | 📦 | Like *Endless 5*, but slower, with `game_over_grace` 0 and no warnings (`board_full_warn_cost` large). |
| **Picture Rally**: pictures appear in a side box, and you spell what you see. | 📦 | `hint_board_formula` for a box beside the board, `joker_image_hints`, `show_hint_word` off. For picture word lists. |
| **First Steps** for any word list: a short tutorial path from the list's `tutorial-words`. | 📦 | `lang_tutorial` levels, then normal ones, like the original's tutorial levels. |
| **Daily Challenge**: the same board for everyone each day, ranked on the score board. | 🛠 | A random generator seeded by the date, plus a daily scope on the score server. |
| **Two-player hot seat**: take turns on one device. | 🛠 | Turn handling and two score panels. |

## Skins

| Idea | Kind | How |
|---|---|---|
| **High contrast / color-blind friendly**: a palette that works for every type of color blindness, black text, a thick grid. | 📦 | `piece-custom-colors` with a color-blind-safe palette, `grid-line-width` 2. |
| **Light mode**: a light background with dark text. | 📦 | `background`, `text` and `grid` colors, plus a light `background.png`. |
| **Wooden tiles** in a board-game style, or chalkboard. | 📦 | `piece-overlay` with a wood-grain PNG, `piece-corner-radius` 0.1, matching backgrounds. |
| **Checkerboard**: tiles colored by their position, not their letter. | 📦 | `chess-colors-mod` 2 with `chess-color-0`/`-1` (and text colors). It shows on the main menu and level selector. |
| **Seasonal** skins (winter, spring, holidays). | 📦 | Backgrounds, a `pause-curtain` picture, and decoration icons (`decorator-bomb` as a snowball …). |
| **A custom font**, e.g. one easier to read for people with dyslexia. | 🛠 | Skins can name a font (`global/skin/fonts/default`), but the web version can't load font files from a zip yet. |

## Features

| Idea | Kind | Notes |
|---|---|---|
| **Play offline** and install as an app. | 🛠 | A service worker that caches the game and the selected word lists. The web app manifest is already there. |
| **Share a level or word list by link**, e.g. a link that opens the game with someone's own words. | 🛠 | Put the words (or a zip URL) in the link; the game imports it on opening. |
| **Shake for a hint** and **voice choice**. | 🛠 | From the feature scan: the DeviceMotion API, and the Web Speech voice list. |
| **Emoji avatar** on the score board. | 🛠 | The server already stores an `icon`; it needs a picker in CONF. |
| **Achievements** made from the wallet: "100 words", "a bomb chain", "all levels of Learning". | 🛠 | Local first; optionally shown on the score board. |
| **A level editor** in the browser: edit a level's rules with sliders and play it right away, then export the zip. | 🛠 | The original had the start of one ("programmable levels"). The settings pages (`prefs`) already show how. |
| **Screen reader support** (letters announced, keyboard play). | 🛠 | Keyboard play exists; add ARIA labels and announcements. |
| **More catalog content**: put new zips on the "SpellMaze More" site so every player can download them from CONF. | 📦 + repo | Add them to `data/more/<domain>/directory.plist` with an icon, poster, description and `version`. |

---

**Good first projects**, which need no code and quickly give players something new:
1. a *Kids* game plus a phonics word list with pictures
2. a *Spelling Bee* game plus grade-level lists with definitions
3. a *Shapes* game
4. a high-contrast skin
5. an *Equations* word list

Publish them in the catalog so they appear under Get More.
